# Conventions

- Model files follow the datamodels.jp layout and rules (schema.json, catalog.yaml with ja+en, examples/example.json, notes.yaml, optional mapping/*.yaml); `datamodels check` enforces them.
- Every model needs both ja and en (node.yaml `languages`).
- Commit style: conventional prefixes (`feat:`, `fix:`, `chore:`) with PR number.
